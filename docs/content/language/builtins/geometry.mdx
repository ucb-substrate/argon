# Geometry built-ins

These constructors add geometry to the current cell. Coordinate arguments are [`Float`](/language/types/scalars#float) expressions.

## `rect`

<ApiItem id="rect" name="rect" signature={'rect(layer: String, x0?, y0?, x1?, y1?, w?, h?, x0i?, y0i?, x1i?, y1i?) -> Rect'} summary={<>Draws an axis-aligned rectangle on a layer.</>}>

<ParameterTable rows={[
  {name: 'layer', type: 'String', typeHref: '/language/types/scalars#string', requirement: 'Required, positional', description: 'A drawing layer from the technology file.'},
  {name: 'x0', type: 'Float', typeHref: '/language/types/scalars#float', requirement: 'Optional keyword', description: 'Constrains the left edge.'},
  {name: 'y0', type: 'Float', typeHref: '/language/types/scalars#float', requirement: 'Optional keyword', description: 'Constrains the bottom edge.'},
  {name: 'x1', type: 'Float', typeHref: '/language/types/scalars#float', requirement: 'Optional keyword', description: 'Constrains the right edge.'},
  {name: 'y1', type: 'Float', typeHref: '/language/types/scalars#float', requirement: 'Optional keyword', description: 'Constrains the top edge.'},
  {name: 'w', type: 'Float', typeHref: '/language/types/scalars#float', requirement: 'Optional keyword', description: 'Constrains the width, x1 - x0.'},
  {name: 'h', type: 'Float', typeHref: '/language/types/scalars#float', requirement: 'Optional keyword', description: 'Constrains the height, y1 - y0.'},
  {name: 'x0i', type: 'Float', typeHref: '/language/types/scalars#float', requirement: 'Optional fallback', description: 'Initial left edge, used when x0 is otherwise free.'},
  {name: 'y0i', type: 'Float', typeHref: '/language/types/scalars#float', requirement: 'Optional fallback', description: 'Initial bottom edge, used when y0 is otherwise free.'},
  {name: 'x1i', type: 'Float', typeHref: '/language/types/scalars#float', requirement: 'Optional fallback', description: 'Initial right edge, used when x1 is otherwise free.'},
  {name: 'y1i', type: 'Float', typeHref: '/language/types/scalars#float', requirement: 'Optional fallback', description: 'Initial top edge, used when y1 is otherwise free.'},
]} />

<Returns type="Rect" href="/language/types/rect">The rectangle.</Returns>

```argon
let gate = rect("poly", x0=0., y0=0., w=80., h=400.);
```

Give enough values or constraints to pin the rectangle down. If you drag an under-constrained rectangle in the GUI, it adds the missing initial values.

</ApiItem>

## `polygon`

<ApiItem id="polygon" name="polygon" signature={'polygon(layer: String, points: Int, x0?, y0?, …, x0i?, y0i?, …) -> Polygon'} summary={<>Creates a polygon with a fixed number of vertices, each constrained on its own.</>}>

  {name: 'yN', type: 'Float', typeHref: '/language/types/scalars#float', requirement: 'Optional keyword', description: 'y coordinate of vertex N.'},
  {name: 'xNi', type: 'Float', typeHref: '/language/types/scalars#float', requirement: 'Optional fallback', description: 'Initial x coordinate of vertex N.'},
  {name: 'yNi', type: 'Float', typeHref: '/language/types/scalars#float', requirement: 'Optional fallback', description: 'Initial y coordinate of vertex N.'},
]} />

<Returns type="Polygon" href="/language/types/polygon">The polygon.</Returns>

```argon

    x0=0., y0=0.,
    x1=100., y1=0.,
    x2=50., y2=80.,

```

</ApiItem>
