# `std::symbol`

`std::symbol` is the standard library module that draws a cell's symbol: the shapes, text, and pins a parent's schematic draws each instance of the cell with. See [Symbols](/language/schematic#symbols) for how a symbol fits into a cell.

## Importing

Nothing in `std::symbol` is in scope by default. Import the names a module uses:

```argon
use std::symbol::{Align, circle, inst_name, line, param, pin, polygon, rect, text};
```

`rect`, `polygon`, and `text` also exist in [`std::layout`](/language/std-layout), so a module that draws both views imports one set under aliases, or calls one by full path. A bare `rect` that nothing imports is reported as having moved to `std::layout`.

Every call returns `()`. Coordinates are keyword arguments in grid units, and are required. Shape and text coordinates are `Float`, so arrows and bubbles can fall between grid points; pin coordinates are `Int`, so a parent's wires end on the grid. A `Float` that depends on constraints waits until it is solved. A value that isn't a finite number is an error.

```argon

    Right,
```

## Device helpers {#device-helpers}

`std::symbol` also draws the device symbols, as Argon functions over the natives above. Each one draws its shapes, its pins, and `inst_name`, with its terminals in the order the device kind takes them. A cell that wraps one device can draw itself as that device by calling the helper on its ports.

| Helper | Pins |
| --- | --- |
| `mos(d, g, s, b)`, `nmos(d, g, s, b)` | `d` (0, 2), `g` (-2, 0), `s` (0, -2), `b` (2, 0) |
| `pmos(d, g, s, b)` | `s` (0, 2), `g` (-2, 0), `d` (0, -2), `b` (2, 0) |
| `res(p, n)`, `cap(p, n)`, `diode(p, n)` | `p` (0, 2), `n` (0, -2) |
| `bjt(c, b, e)`, `npn(c, b, e)` | `c` (0, 2), `b` (-2, 0), `e` (0, -2) |
| `pnp(c, b, e)` | `e` (0, 2), `b` (-2, 0), `c` (0, -2) |
| `bjt4(c, b, e, sub)`, `npn4(c, b, e, sub)`, `pnp4(c, b, e, sub)` | The pins of the 3-terminal helper, plus `sub` (2, 0). |

```argon
cell mos(nfet: Bool, w: Float, nf: Int) {
    pub let d = Signal();
    pub let g = Signal();
    pub let s = Signal();
    pub let b = Signal();
    device(DeviceKind::Subckt, [d, g, s, b], model, l=0.15, w=w, nf=nf);

    if nfet {
        std::symbol::nmos(d, g, s, b);
    } else {
        std::symbol::pmos(d, g, s, b);
    };
}
```

The GUI draws a raw `device` with the helper for its kind and terminal count, so a wrapper cell and the device it wraps look the same. A `Subckt` device is drawn as a box with numbered pins.
