# Standard library

The `std` module is written in Argon itself. Call its functions with the `std::` prefix, or import them with [`use`](/language/modules-manifests#imports), as in `use std::{max, min};`.

Layout functions live in the submodule [`std::layout`](/language/std-layout): the geometry constructors, `inst`, `bbox`, `dimension`, and helpers such as `std::layout::array` and `std::layout::intersection`.

## `std::Option` {#option}

```argon
enum Option<T> {
    Some(T),
    None,
}
```

A value that may be absent. `Option`, `Some`, and `None` are in scope in every module without a `use`. A cell parameter typed `Option<Int>` with a `None` default is optional, and a struct field typed `Option<Node>` lets a struct contain itself. Take an `Option` apart with `match`:

```argon
fn count(n: Option<Int>) -> Int {
    match n {
        Some(value) => value,
        None => 1,
    }
}
```
