# `std::layout`

`std::layout` is the standard library module that builds layout: geometry constructors, instance placement, bounding boxes, dimensions, and helpers for working with rectangles.

## Importing

Nothing in `std::layout` is in scope by default. Import the names a module calls with a grouped `use` at the top of the file:

```argon
use std::layout::{crect, inst, rect};

cell pad(w: Float, h: Float) {
    pub let metal = rect("met1", x0=0., y0=0., w=w, h=h);
}

cell top() {
    let p = inst(pad(100., 80.), x=0., y=0.);
    let keepout = crect(x0=p.x - 20., y0=p.y - 20., w=140., h=120.);
}
```

A `use` applies only to the file that declares it, so each module imports what it calls. You can also call an item by its full path, as in `std::layout::rect("met1")`, or import it under another name with `use std::layout::rect as r;`. A module may declare its own item named `rect` or `inst`; to use the `std::layout` one as well, import it under an alias or call it by full path. See [imports](/language/modules-manifests#imports) for the full `use` syntax.

`rect`, `crect`, `polygon`, `path`, `text`, `inst`, `bbox`, and `dimension` are implemented by the compiler. They can only be called, so a reference that isn't a call, such as `let f = rect;`, is an error. The [rectangle helpers](#rectangle-helpers) are ordinary Argon functions.

The examples below assume the names they call are imported. Signatures use the [built-in notation](/language/builtins#signature-notation).

## Rectangle helpers

These functions are written in Argon on top of `rect` and `crect`.

```argon
use std::layout::{array, center_rects, crect, rect};

cell via_row(n: Int) {
    let met1 = rect("met1", x0=0., y0=0., w=400., h=60.);
    let cut = crect(layer="via1", x0=0., y0=0., w=20., h=20.);
    let vias = array(cut, n, 40., 0.);
    center_rects(vias, met1);
}
```
