# Scalar and utility types

## `Float` {#float}

`Float` is the type of coordinates, distances, and other solver expressions. A float literal has a decimal point, an exponent, or both: `12.`, `-0.5`, `1e-12`, or `2.5e3`.

Used by the [geometry constructors](/language/std-layout#geometry), [constraints](/language/builtins/constraints), and instance positions.

:::warning
`12` is an `Int`. Write `12.` for a float.
:::

## `Int` {#int}

`Int` is for counts, indices, point counts, and rotation angles. Schematic [placement and routes](/language/schematic-drawing#placement-and-routes) are `Int` grid units, not `Float`.

Cast to a float with `value as Float`.

## `Bool` {#bool}

`Bool` is `true` or `false`. Conditions must be booleans, and [`inst`](/language/std-layout#inst) uses them for flags such as `reflect` and `construction`.

## `String` {#string}

`String` is text. Layer names and labels are strings.

```argon
std::layout::rect("met1");
std::layout::text("VDD", "text.label", 0., 0.);
```

`+` joins two strings, [`std::to_string`](/language/std#to-string) writes a number or a `Bool`, and [`std::format`](/language/std#format) fills a template's `{}`s. Strings compare with `==` and `!=`, but not with `<` or `>`.

```argon
let implant = if nfet { "nsdm.drawing" } else { "psdm.drawing" };
let port = "d_" + std::to_string(i);
let name = std::format("r{}c{}", [row, col]);
let metal = layer == "met1.drawing";
```

`+` joins only strings, so convert a number first: `"w" + 1` is an error.

## `Any` {#any}

`Any` erases a value's static type. It's occasionally useful for mixed or generic sequences, but concrete types give you field access and better error messages.

## Unit `()` {#unit}

`()` is the return type of functions that produce nothing useful, such as ones that only emit geometry or constraints.

```argon
fn align_left(a: Rect, b: Rect) -> () {
    eq(a.x0, b.x0);
}
```
