# `std::schematic`

`std::schematic` is the standard library module that builds a cell's schematic: signals, the connections between them, devices, and schematic instances of other cells. See [Schematics](/language/schematic) for how these fit together.

## Importing

Nothing in `std::schematic` is in scope by default. Import the names a module uses:

```argon
use std::schematic::{DeviceKind, Signal, connect, device};
use std::schematic::inst as sinst;
```

`std::layout` also has an `inst`, so a module that places cells in both views imports at least one of them under another name, or calls it by full path. A name such as `Signal` is only in scope once imported, in type position as well as in calls.

`Signal`, `connect`, `device`, and `inst` are implemented by the compiler. They can only be called, so a reference that isn't a call, such as `let f = connect;`, is an error. `DeviceKind` is an ordinary enum.

## `DeviceKind` {#devicekind}

```argon
enum DeviceKind {
    Mos,
    Res,
    Cap,
    Diode,
    Bjt,
    Subckt,
}
```

The kind of a device placed with [`device`](#device): a MOSFET, a resistor, a capacitor, a diode, a bipolar transistor, or an instance of a subcircuit the cell does not define, such as a PDK model.
