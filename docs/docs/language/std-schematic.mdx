# `std::schematic`

`std::schematic` is the standard library module that builds a cell's schematic: signals, the connections between them, devices, and schematic instances of other cells. See [Schematics](/language/schematic) for how these fit together.

## Importing

Nothing in `std::schematic` is in scope by default. Import the names a module uses:

```argon
use std::schematic::{Device, DeviceKind, Signal, connect, device, signals};
use std::schematic::inst as sinst;
```

`std::layout` also has an `inst`, so a module that places cells in both views imports at least one of them under another name, or calls it by full path. A name such as `Signal` or `Device` is only in scope once imported, in type position as well as in calls.

`Signal`, `connect`, `device`, and `inst` are implemented by the compiler. They can only be called, so a reference that isn't a call, such as `let f = connect;`, is an error. `Device` is only a type. `DeviceKind` is an ordinary enum, and `signals` an ordinary function.

The placement keywords `x`, `y`, `angle`, and `reflect`, and the `route` of a connection, are [grid units](/language/schematic#placement-and-routes) that only say where the GUI draws an element. None of them can be read back.

## `Device` {#device-type}

The type of the handle [`device`](#device) returns. Its fields are the device's terminals, named by its kind, and `terminals`, every terminal in order:

| Kind | Fields |
| --- | --- |
| `Mos`, `Nmos`, `Pmos` | `d`, `g`, `s`, `b` |
| `Res`, `Cap`, `Diode` | `p`, `n` |
| `Bjt`, `Npn`, `Pnp` | `c`, `b`, `e`, and `sub` with 4 terminals |
| `Subckt` | none by name |
| every kind | `terminals: [Signal]` |

Every named field has type `Signal`. The names are checked against the device's kind when the cell runs, so `r.g` on a resistor is an error. See [device handles](/language/schematic#device-handles).

## `DeviceKind` {#devicekind}

```argon
enum DeviceKind {
    Mos,
    Nmos,
    Pmos,
    Res,
    Cap,
    Diode,
    Bjt,
    Npn,
    Pnp,
    Subckt,
}
```

The kind of a device placed with [`device`](#device): a MOSFET, a resistor, a capacitor, a diode, a bipolar transistor, or an instance of a subcircuit the cell does not define, such as a PDK model. `Nmos` and `Pmos` are `Mos` devices, and `Npn` and `Pnp` are `Bjt` devices, drawn with a polarity symbol; they netlist as their base kind.
