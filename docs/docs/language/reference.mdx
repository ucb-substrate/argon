# Quick reference

This page lists what writing a generator needs, one line per item, with links to the chapters that explain each one. Lengths are `Float`s in nm.

## A complete library

A SKY130 library is a directory with a manifest and a source file. The manifest's paths are relative to it, so point them at the Argon repository's `pdks/sky130`:

```toml title="Argon.toml"
name = "mylib"
tech = "../argon/pdks/sky130/sky130.tech.toml"

[dependencies]
sky130 = "../argon/pdks/sky130"
```

This one transistor passes DRC and LVS at any width of at least 420 and any finger count. Export it with `arc run --cell 'nfet(1000., 2)' --gds --spice`.

```argon title="lib.ar"
use sky130::{mos, tap_m1};
use std::layout::{center_rects, inst, rect, text};
use std::schematic::{DeviceKind, Signal, device};

/// An NMOS with a substrate tap column, its terminals labeled as ports.
cell nfet(w: Float, nf: Int) {
    pub let d = Signal();
    pub let g = Signal();
    pub let s = Signal();
    device(DeviceKind::Nmos, [d, g, s, s], "sky130_fd_pr__nfet_01v8", w=w * (nf as Float) / 1000., l=0.15, nf=nf);

    let m = inst(mos(true, w, nf), x=0., y=0.);
    let t = inst(tap_m1(false, 250., w));
    eq(t.tap.x1, m.sdm.x0 + 130. - 270.);
    eq(t.tap.y0, m.sdm.y0 + 130.);
    // The source bar reaches the tap column on met1.
    rect("met1.drawing", x0=t.m1.x0, x1=m.s.x1, y0=m.s.y0, y1=m.s.y1);
    pin("d", m.d);
    pin("g", m.g);
    pin("s", t.m1);
}

/// Labels a port with a met1 pin at the center of `r`.
fn pin(name: String, r: Rect) {
    let p = rect("met1.pin", w=140., h=140.);
    center_rects(r, p);
    text(name, "met1.label", p.x0 + 70., p.y0 + 70.);
}
```

## Language

- **Items.** A module declares `cell`s, `fn`s, `struct`s, and `enum`s, and imports with `use std::layout::{inst, rect};`. Items resolve across the whole module, so a cell can instantiate a cell or call a function declared further down. See [cells and functions](/language/cells-functions).
- **Parameters.** A parameter written `name: Type` is positional. One with a default, `h: Float = w`, is a keyword parameter: pass it by name or leave it out. A positional parameter can't be passed by name. See [keyword parameters](/language/cells-functions#keyword-parameters).
- **Fields.** A cell's top-level `let`s are its fields, and an instance reads only its `pub let`s. `x` and `y` can't be fields: they are an instance's position.
- **Types.** A `Float` literal needs a decimal point or an exponent, as in `12.` or `1e3`; `12` is an `Int`. An instance's type can't be written, so annotate one as `Any`. An `Option<T>` is `Some(value)` or `None`. See [types and values](/language/types-values).
- **Operators.** `+`, `-`, `*`, and `/` take two `Int`s or two `Float`s, never one of each; convert with `as Float` and `as Int`. `+` also joins two `String`s. `%` takes `Int`s. `Int` division and `as Int` truncate toward zero, so `-0.5 as Int` is `0`. There are no power or bitwise operators. `==` and `!=` reject `Float`s; `<`, `<=`, `>`, and `>=` take numbers. `&&`, `||`, and `!` take `Bool`s.
- **Schematics.** `pub let vdd = Signal();` declares a port, in declaration order, and `let n = Signal();` an internal net. `device(DeviceKind::Nmos, [d, g, s, b], "sky130_fd_pr__nfet_01v8", w=w, l=0.15, nf=nf)` adds a transistor, and its keyword arguments go to the netlist as written, so for SKY130 `w` and `l` are in µm and `w` is the total width of all fingers. The other kinds are `Pmos`, `Mos`, `Res`, `Cap`, `Diode`, `Npn`, `Pnp`, `Bjt`, and `Subckt`. See [schematics](/language/schematic).
- **Strings.** A `String` is text, such as a layer name. `+` joins two, `==` and `!=` compare them, and `std::to_string(i)` writes an `Int`, so `"d_" + std::to_string(i)` is the name of `d[i]`'s port when `pub let d = signals(n);`.
- **Control flow.** `if`/`else` and `match` are expressions. `for x in xs { ... }` runs once per element, `[for x in xs { value }]` builds a sequence, and `std::range(n)` is `[0, 1, …, n - 1]`. Functions and cells may recurse. See [control flow](/language/control-flow).
- **Constraints.** Coordinates are solved: a coordinate keyword such as `x0=0.` is an equation, and `eq(a, b)` adds one. Comparisons, casts, and `std::max` or `std::min` on a coordinate wait until it's determined; both also take `Int`s. Solved coordinates must lie on the technology's grid, 5 nm in SKY130, so center with `center_rects` and round with `grid_floor` rather than dividing by 2. See [constraints](/language/constraints).
- **Emission.** `value!` emits a value for the GUI to list in its hierarchy. It adds no exported geometry and no constraint.
- **Errors.** A static error, such as a type error, anywhere in a library stops every cell from compiling. An error while a cell runs names the failing line and the call in the cell's body that led to it.

## Types

- [`Rect`](/language/types/rect): `x0`, `y0`, `x1`, `y1`, `w`, `h`: Float; `layer`: String.
- [`Polygon`](/language/types/polygon): `layer`: String; `points`: [Point]; `xN`, `yN`: Float.
- [`Path`](/language/types/path): `layer`: String; `points`: [Point]; `xN`, `yN`, `width`, `begin_extension`, `end_extension`: Float.
- [`Point`](/language/types/point): `x`, `y`: Float.
- [`Inst`](/language/types/instance): `x`, `y`: Float; `<cell field>`: Declared type.
- [`SchematicInst`](/language/types/instance): `<cell field>`: Declared type.

## [`std::layout`](/language/std-layout)

- `rect(layer: String, x0?, y0?, x1?, y1?, w?, h?, x0i?, y0i?, x1i?, y1i?, net?) -> Rect`: Draws an axis-aligned rectangle on a layer.
- `crect(x0?, y0?, x1?, y1?, w?, h?, layer?, x0i?, y0i?, x1i?, y1i?) -> Rect`: Creates a construction rectangle: usable in constraints and as bounds, but not exported.
- `polygon(layer: String, points: Int, x0?, y0?, …, x0i?, y0i?, …) -> Polygon`: Creates a polygon with a fixed number of vertices, each constrained on its own.
- `path(layer: String, points: Int, width?, begin_extension?, end_extension?, x0?, y0?, …) -> Path`: Creates a constant-width path along a centerline.
- `text(value: String, layer: String, x: Float, y: Float) -> ()`: Places a text label on a layer.
- `inst(cell: Cell, reflect?, angle?, x?, y?, xi?, yi?, construction?) -> Inst`: Places a cell in the current scope.
- `bbox(value: Cell | Inst | Rect) -> Rect`: Returns the bounding box of a cell, a placed instance, or a rectangle, as a construction rectangle.
- `bbox_of(items: [Any]) -> Rect`: Returns the bounding box of a non-empty sequence of instances or rectangles.
- `shapes(value: Cell | Inst, layer: String) -> [Rect]`: Returns the bounding rectangle of every shape on one layer of a cell or a placed instance, through all of its instances.
- `row(insts: [Any], gap: Float) -> ()`: Places each instance <code>gap</code> right of the one before.
- `column(insts: [Any], gap: Float) -> ()`: Places each instance <code>gap</code> above the one before.
- `autoroute(area: Rect, layers: [RouteLayer], vias: [RouteVia], obstacles: [[Rect]], nets: [RouteNet]) -> [RoutedNet]`: Routes nets between their pins and draws the wires, pin stubs, and vias.
- `route_tracks(area: Rect, layers: [(Float, Float, Bool)], vias: [(Float, Float, (Float, Float), (Float, Float))], obstacles: [(Int, Rect)], nets: [(String, [(Int, Rect)])]) -> [([(Int, Rect)], [(Int, [Rect], Rect, Rect)], [(Int, Rect)])]`: Routes nets as <code>autoroute</code> does and returns the geometry without drawing it.
- `dimension(p: Float, n: Float, value: Float, coord: Float, pstop: Float, nstop: Float, horizontal: Bool) -> ()`: Adds an equality constraint together with the dimension label the GUI draws for it.
- `rule(name: String) -> Float`: Reads a design rule's value, such as <code>"met1.space"</code>, from the technology file.
- `via(bot: Rect, top: Rect) -> Rect`: Draws the largest array of cuts that fits where two shapes on adjacent layers overlap, with the enclosures the technology file requires.
- `via_stack(bot: Rect, top: Rect) -> [Rect]`: Joins two shapes through every layer between theirs, with a via per layer and a pad on each layer in between.
- `intersection(rect1: Rect, rect2: Rect) -> Rect`: The overlap of two rectangles, as a construction rectangle.
- `union(rect1: Rect, rect2: Rect) -> Rect`: The smallest construction rectangle containing both inputs.
- `array(r: Rect, n: Int, xpitch: Float, ypitch: Float) -> Rect`: Draws a row of rectangles and returns its bounds.
- `array2(r: Rect, nx: Int, ny: Int, xpitch: Float, ypitch: Float) -> Rect`: Draws a grid of rectangles and returns its bounds.
- `max_array(r: Rect, w: Float, h: Float, xpitch: Float, ypitch: Float) -> Rect`: Draws the largest grid of rectangles that fits in a given width and height.
- `eq_rect(r1: Rect, r2: Rect) -> ()`: Constrains two rectangles to coincide.
- `center_rects(r1: Rect, r2: Rect) -> ()`: Constrains two rectangles to share a center, as closely as the grid allows.
- `crect2rect(r: Rect) -> Rect`: Draws a rectangle with the same layer and edges as a construction rectangle.
- `mirror_pair(c: Cell, axis: Float) -> [Inst]`: Places two copies of a cell, mirror images of each other about a vertical line.
- `eq_mirror(a: Rect, b: Rect, axis: Float) -> ()`: Constrains two rectangles to be mirror images about a vertical line.
- `common_centroid(n: Int) -> [Bool]`: The order of a common-centroid row of two devices' units: A B B A A B B A, and so on.
- `interdigitated(n: Int) -> [Bool]`: The order of an interdigitated row of two devices' units: A B A B, and so on.

## [`std::schematic`](/language/std-schematic)

- `Signal(x=Int, y=Int, angle=Int) -> Signal`: Creates a signal of the current cell.
- `connect(a: Signal, b: Signal, route=[(Int, Int)]) -> ()`: Joins the nets of two signals.
- `device(kind: DeviceKind, terminals: [Signal], model: String, <name>=Float | Int | String, …, x=Int, y=Int, angle=Int, reflect=Bool) -> Device`: Adds a primitive device to the current cell.
- `inst(cell: Cell, x=Int, y=Int, angle=Int, reflect=Bool) -> SchematicInst`: Places a cell in the current cell's schematic.
- `signals(n: Int) -> [Signal]`: Creates fresh signals.

## [`std`](/language/std)

- `std::max<T>(x0: T, x1: T) -> T`: Returns the greater of two <code>Int</code>s or two <code>Float</code>s.
- `std::min<T>(x0: T, x1: T) -> T`: Returns the lesser of two <code>Int</code>s or two <code>Float</code>s.
- `std::max_of<T>(items: [T]) -> T`: Returns the greatest of a non-empty sequence of <code>Int</code>s or <code>Float</code>s.
- `std::min_of<T>(items: [T]) -> T`: Returns the least of a non-empty sequence of <code>Int</code>s or <code>Float</code>s.
- `std::is_some<T>(o: Option<T>) -> Bool`: Whether an option holds a value.
- `std::is_none<T>(o: Option<T>) -> Bool`: Whether an option is empty.
- `std::unwrap_or<T>(o: Option<T>, default: T) -> T`: The value inside an option, or a default.
- `std::first<T>(items: [T]) -> Option<T>`: Returns the first element of a sequence, if it has one.
- `std::last<T>(items: [T]) -> T`: Returns the last element of a sequence.
- `std::len<T>(items: [T]) -> Int`: Returns the number of elements in a sequence.
- `std::concat<T>(first: [T], second: [T]) -> [T]`: Joins two sequences.
- `std::flatten<T>(sequences: [[T]]) -> [T]`: Joins a sequence of sequences.
- `std::sum(values: [Int]) -> Int`: Adds up a sequence of integers.
- `std::sum_float(values: [Float]) -> Float`: Adds up a sequence of floats.
- `std::any(values: [Bool]) -> Bool`: Whether any value is true.
- `std::all(values: [Bool]) -> Bool`: Whether every value is true.
- `std::range(stop: Int) -> [Int]`: Returns the integers from 0 up to stop.
- `std::to_string(value: Int) -> String`: Returns an integer's decimal digits.

## [SKY130 library](/language/sky130)

- `sky130::fet1v8(nfet: Bool, w: Float, nf: Int)`: A 1.8 V transistor with `nf` gate fingers over one diffusion, contacted with local interconnect between and beside the fingers. Fields: `poly_bbox`, `li1_bbox`, `sdm`.
- `sky130::tap(ntap: Bool, w: Float, h: Float)`: A well or substrate tap: a `w` by `h` tap diffusion covered with local interconnect and as many contacts as fit on a 340 pitch. Fields: `tap`, `li1`, `sdm`.
- `sky130::tap_m1(ntap: Bool, w: Float, h: Float)`: A `tap` with met1 over its whole outline, contacted to its local interconnect with as many mcons as fit, so a supply can strap it directly. Fields: `tap`, `li1`, `sdm`, `m1`.
- `sky130::fill_tap(ntap: Bool, span: Rect) -> Any`: Places a `tap_m1` whose implant fills `span` exactly, such as the room at the end of a row, and returns the instance.
- `sky130::mos(nfet: Bool, w: Float, nf: Int, gate_row: Int = 0, gate_side: Int = 0, swap: Bool = false, away: Bool = false, straps: Bool = true)`: A `fet1v8` wired on met1: its gate fingers join a poly pad below the diffusion, contacted under the met1 bar `g`, and the met1 bars `s` and `d` strap its sources (even contact columns, counting from 0 at the left) and its drains (odd columns). Fields: `sdm`, `poly`, `cols`, `s`, `d`, `g`.
- `sky130::fold(nfet: Bool, w: Float, nf: Int, rows: Int)`: One transistor folded into `rows` rows of `mos`, each with `nf / rows` fingers, stacked upward on a pitch of `w + 1000`, so a long device fits the height a taller neighbor sets. Fields: `devices`, `sdm`, `s`, `d`, `g`.
- `sky130::cmos(nw: Float, pw: Float, nf: Int, rows: Int = 1, gate_row: Int = 0, gate_side: Int = 0)`: An NMOS and a PMOS `fet1v8` sharing `nf` gate fingers, as in an inverter: the NMOS below, the PMOS above in an n-well, and the gate contacted on the met1 bar `g` between them, with the drain bars on either side of it. Fields: `cols`, `n_sdm`, `n_s`, `n_d`, `p_cols`, `p_sdm`, `p_d`, `p_s`, `poly`, `g`, `nwell`.
- `sky130::gate_contact(fingers: Rect, li_y0: Float, pad_y1: Float, side: Int, npc_y0: Float, npc_y1: Float) -> Rect`: Contacts the gate fingers spanning `fingers` on met1: a poly pad from 80 below `li_y0` to `pad_y1`, li1 170 tall from `li_y0`, the nitride cut from `npc_y0` to `npc_y1`, and the met1 bar 320 tall that it returns.
- `sky130::strap(x0: Float, y: Float, n: Int, below: Float, draw: Bool) -> Rect`: A met1 bar 320 tall over `n` mcons at `y`, on every other contact column from the one at `x0`, reaching `below` under them.
- `sky130::abut(devices: [Any])`: Places each `mos` or `cmos` instance of `devices` right of the one before, with its leftmost contact column on that one's rightmost, so their diffusions merge and the shared column is a terminal of both.
- `sky130::inv(nw: Float, pw: Float, nf: Int)`: A CMOS inverter drawn from `fet1v8` and `tap`, with taps under the NMOS and over the PMOS, and its gate and output on local interconnect. Fields: `ptap`, `pmos`, `ntap`, `nwell`, `a_li_mid`, `o_li_right`.
