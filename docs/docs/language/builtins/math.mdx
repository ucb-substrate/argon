# Math built-ins

These pick one of two numbers without opening a scope, so they suit inner loops. [`std::max`](/language/std#max) and [`std::min`](/language/std#min) wrap the `Float` versions.

## `max_float`

<ApiItem id="max-float" name="max_float" signature={'max_float(a: Float, b: Float) -> Float'} summary={<>Returns the larger of two floats.</>}>

<ParameterTable rows={[
  {name: 'a', type: 'Float', typeHref: '/language/types/scalars#float', requirement: 'Required, positional', description: 'Returned when the two are equal.'},
  {name: 'b', type: 'Float', typeHref: '/language/types/scalars#float', requirement: 'Required, positional', description: 'Returned when it is larger.'},
]} />

<Returns type="Float" href="/language/types/scalars#float">b if a is less than b, otherwise a.</Returns>

Like a comparison, it compares values snapped to the manufacturing grid, and waits until the solver has fixed both.

</ApiItem>
